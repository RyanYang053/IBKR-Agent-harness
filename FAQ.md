# IBKR Agent Harness FAQ

## Can the agent submit orders?

No. The harness does not implement brokerage order submission.

## Can I connect a cloud model?

Use the public-only MCP surface and inspect your client configuration. This is application-level isolation, not a hardware security guarantee.

## Do I need IBKR credentials for the demo?

No. It uses a synthetic Flex statement and illustrative valuation inputs.

## Is it available on PyPI?

The package manifest exists; installation from this repository is the supported documented path until a verified registry release is published.
