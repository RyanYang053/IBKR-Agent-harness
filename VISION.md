# Vision

Give agents deterministic financial primitives and explicit boundaries. A user should be able to inspect the inputs and reproduce calculations without giving a model authority over the brokerage account.

## Principles

- Deterministic math and reproducible evidence before model interpretation.
- Explicit permissions and human authority; do not broaden execution or access by default.
- Honest documentation of verification scope, limitations and failed results.
- Synthetic examples and small, reviewable contributions.
